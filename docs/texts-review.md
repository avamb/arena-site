# Three lines on any site

The widget is a web component. Drop it on any page, style it with CSS variables, listen to its events. Everything else is a public API with signed webhooks.

## How do I put tickets on my site?

```html
<script type="module" src="https://tickets.arenasoldout.com/widget/v1/arena-tickets.js"></script>
<arena-tickets feed-token="YOUR_FEED_TOKEN" locale="en"></arena-tickets>
```

- `--arena-accent`: Your colours: the widget reads --arena-accent, --arena-radius, --arena-bg and --arena-border-color from your page
- `locale`: Buyer language: en, ru, cs, he, es; Hebrew is right-to-left
- `arena:order_paid`: Widget events arena:* for your analytics and your own thank-you pages
- `feed-token`: One token per sales channel; revoke it in the event center at any time

[Get a feed token](https://new.arenasoldout.com/start)

## What can I do through the API?

### Event bundle in one call

One request creates the event, its sessions, the venue, prices, the poster and the publication. The same shape the Telegram bot uses.



### Signed webhooks

Orders, payments, refunds and session changes are delivered to your endpoint with a signature you verify. Retries with backoff.



### Scoped API keys

A key sees one organization and only the scopes you grant. Rotate and revoke keys in the event center.



### WordPress plugin

Orders land in WooCommerce, the shop keeps working, the seating plan and the ticket come from Arena. The plugin is how two clients moved from Bil24 with zero downtime.



### Imports

Sessions, seating plans and customers imported from Bil24. Other systems through the event bundle and a CSV of customers.



### OpenAPI

The OpenAPI description is published with the API. Ask the team for the current file until it is linked here automatically.
