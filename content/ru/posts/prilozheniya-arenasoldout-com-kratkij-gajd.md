Десктопные приложения (для настольных компьютеров) билетной платформы ArenaSoldOut.com реализованы на Java и выполняются в операционных системах семейств Windows, Mac OS, Linux, Solaris.

Приложения на платформе разделены по функциональности, чтобы каждый пользователь мог использовать необходимый для него инструмент без задержек. Это обеспечивает доступ к необходимым функциям для эффективной работы, позволяет пользователям предоставлять персоналу различные уровни доступа для оперативного и корректного внесения изменений, минимизируя нагрузку на компьютеры и мобильные устройства.

**МЕНЕДЖЕР (MANAGER)**

Приложение Менеджер предназначено для управления учётными данными предприятий, бизнесов и их сотрудников (пользователей), для создания интерфейсов и управления ими, для контроля подписок на мероприятия, конфигурирования WEB WIDGET, и других задач по настройке и управлению ресурсами билетной платформы.

Приложение МЕНЕДЖЕР (MANAGER) – основное, в котором компании, или физические лица создают свои аккаунты на платформе.

В приложении МЕНЕДЖЕР (MANAGER) создаются учетные записи компаний и физических лиц, вводятся данные сотрудников (пользователей Приложений), создаются подписки на мероприятия между Организаторами и Агентами по продажам.

**РЕДАКТОР (EDITOR)**

Редактор предназначен для создания событий (мероприятий), внесения всей необходимой для продажи билетов информации в центральную базу данных ArenaSoldOut.com, для произведения изменений и создания маркетинговых акций. Доступ в приложение имеют только определенные в приложении MANAGER сотрудники.

РЕДАКТОР (EDITOR), как и другие приложения ArenaSoldOut.com, является клиентской частью центрального сервера билетной платформы. Приложением РЕДАКТОР (EDITOR) пользуются только те, кто является Организатором мероприятий. Редактор предназначен для создания событий (представлений) и внесения всей необходимой для продажи билетов информации в центральную базу данных ArenaSoldOut.com. Редактор предоставляет инструменты для создания и управления сеансами представлений, содержит средства подключения агентов по продаже к событиям и элементы управления продажами билетов. В приложении вы можете создавать любые типы мероприятий, как с размещением на местах (assigned seats), без размещения (general admission) и комбинированные схемы (combined)

**REPORTER**

Приложение REPORTER предназначено для получения и анализа данных о продажах билетов, получения отчетов различных форм, возврата билетов. Приложение отображает данные в режиме реального времени.

**ОНЛАЙН КАССА (CASSA)**

Приложение Касса предназначено для продажи билетов в традиционных билетных кассах, а также в офисах партнеров, участников рынка, у других типов партнеров.

**МОБИЛЬНАЯ СКД (МОБИЛЬНАЯ СИСТЕМА КОНТРОЛЯ ДОСТУПА)**

Приложение «Мобильная система контроля доступа» предназначено для проверки билетов, реализованных через билетную платформу ArenaSoldOut.com.

МСКД состоит из клиентской части (мобильного приложения) и серверной части на центральном сервере ArenaSoldOut.com. Клиентская часть МСКД применяется контролерами на входном контроле представления. МСКД может использоваться для проверки билетов, как при входе, так и при выходе. Для работы МСКД требуется оснащенное фотокамерой с автофокусом мобильное устройство с операционной системой Android версии 4.0 и выше, а так же доступ в Интернет для связи с центральным сервером ArenaSoldOut.com. МСКД считывает криптозащищенные QR-коды Мобильных электронных билетов (МЭБ) платформы ArenaSoldOut.com непосредственно с экрана мобильного устройства посетителя.

Мобильное устройство может быть как профессиональным, которым оснащены большинство площадок в мире, так и в случае небольших мероприятий – либо телефоном, либо планшетом, работающим на Android версии 4.0 и выше.

Особенностью МСКД ArenaSoldOut.com является то, что система гладко работает и при прерывающейся интернет связи.

## Как пользователи билетной платформы работают с приложениями:

-   Есть организаторы, которые совмещают все роли. Они и выступают организаторами, и агентами по продаже своих мероприятий (например, когда продают только через свои сайты и свои соцсети)

-   Есть организаторы, которые совмещают все эти роли, продают билеты через свои сайты и соцсети, но при этом также продают через своих партнёров, давая каждому их них свои виджеты продаж, плюс подключают к продажам как Агентов по продажам и онлайн кассы.

-   Роли могут быть разделены. Например, одни создают мероприятие (выступают в ролях Оператор, Организатор), другие работают как агенты по продажам.

-   Агенты по продажам могут выбирать с какими мероприятиями они будут работать. Конечно, в первую очередь это зависит от направленности их бизнеса, например, от локаций, языков, типов мероприятий, или всего вместе.

-   Билетные системы, афиши, или, как в ряде стран называют – билетные кассы, могут создавать свои бизнесы под своим брендом, пользуясь всеми функциями платформы и предоставляя своим клиентам разные типы сервисов.

Платформа ArenaSoldOut.com создана и работает таким образом, чтобы каждый мог эффективно управлять своими проектами, или своим  бизнесом, развивать его в любом сегменте работы на рынке массовых мероприятий.
